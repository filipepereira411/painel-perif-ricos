Quero ser controlado — configurar o agente

Copia este JSON para agent/config.json no PC a controlar e executa start-agent.bat. O agente precisa de Node.js 22+ e Windows.

O endereço aponta para localhost — o agente noutro PC não conseguirá chegar aqui. Usa o IP da rede (ex.: 192.168.1.88:8080).
